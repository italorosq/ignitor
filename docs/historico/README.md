# Histórico

- **2024-11** — primeira versão: duas estações Pico, LoRa 433 MHz, botão e relé.
- **2026-04** — ignição migrou para ESP32-C3; comando continuou no Pico.
- **2026-10** — placas de ignição SMD, PTH e CNC; revisão de fabricação.
- **2026-11** — as duas estações passaram a usar a mesma PCB (ESP32 DevKit V1).
  O comando ganhou OLED e o firmware da ignição perdeu botão, OLED, EXP e ADC.

Os relatórios de auditoria e as versões antigas ficam no histórico do Git.
